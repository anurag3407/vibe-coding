# 🎨 The Vibe Coding Masterclass (Interactive Bauhaus Website)

> **From Zero to Full-Stack, Autonomous Agents, and Web3 in 3 Hours.**  
> A production-grade, multi-page Next.js web application engineered strictly within the **Constructivist Bauhaus Design System** (Red `#D02020`, Blue `#1040C0`, Yellow `#F0C020`, Stark Black `#121212`, Off-White `#F0F0F0`, binary radii, 4px solid borders, and tactile drop-shadows).

---

## 🚀 Live Features & Interactive Simulators

1. **4-Phase Sequential Storyline (12 Lessons)**:
   - **Phase 1: Getting Ready** (Lessons 01–03: Big Idea, 10-Min Dual-OS Setup, Panic Button Protocol)
   - **Phase 2: Directing the AI** (Lessons 04–06: R-G-C-C-O Prompting, CLAUDE.md & Prompt Caching, PRD Blueprints)
   - **Phase 3: The Builder's Toolkit** (Lessons 07–09: UI Lego Bricks, Git Game Saves & AI Conflict Merging, MCP USB-C Hub)
   - **Phase 4: Full-Stack & Launching** (Lessons 10–12: Real Web Apps, `NEXT_PUBLIC_` Secret Safety, Web3 Escrows, 3-Point Visual Test)
2. **Interactive Simulators**:
   - **Emergency Panic Protocol**: Simulated `Ctrl + C` + `git checkout .` to freeze runaway AI and restore clean saves.
   - **Secret Safety Inspector**: Live checker demonstrating why `NEXT_PUBLIC_` variables are visible in browser DevTools.
   - **Visual Test Sandwich**: 3-point verification (UI Click, F12 Console Red Text, Supabase DB Row) for non-technical builders.
   - **Pre-Flight Checklist**: 6-point 24-hour preparation checklist with live progress tracking.
   - **Dual-OS Terminal Switcher**: macOS (Homebrew, zsh) vs Windows (PowerShell, Winget) verified copy-paste commands.
   - **Model Context Protocol (MCP) USB Hub**: Real JSON-RPC inspection for PostgreSQL, Filesystem, GitHub, and Puppeteer.
   - **Web3 Smart Contract Escrow**: Simulated RainbowKit wallet connect, deposit, work delivery, and atomic payout on Base.
   - **Searchable Cheatsheet Hub (`/cheatsheet`)**: 1-click copy for 100+ commands and prompts.

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS (Custom Bauhaus Tokens & Hard Offset Shadows)
- **Icons**: Lucide React
- **Typography**: Google Fonts 'Outfit'
- **Design Philosophy**: 1920s Constructivist Bauhaus (Form follows function)

## 🏃 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/anurag3407/vibe-coding.git
cd vibe-coding
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to explore the website.

### 4. Build for production
```bash
npm run build
npm run start
```
